Third-party software in Tallow
===============================

Tallow, and every game built with it, includes the libraries below. Their licences follow in full.

  bgfx                 Rendering
  bx                   Base library used by bgfx
  bimg                 Image library used by bgfx
  SDL 3                Windows, input and gamepads
  Jolt Physics         Physics
  Rapier3D             Physics (prebuilt C bindings)
  Flecs                Entity component system
  Recast Navigation    Polygon navigation baking and Detour path queries
  meshoptimizer        Cluster LOD (meshoptimizer and its clusterlod example)
  JoltC                C interface to Jolt Physics
  ENet                 Network transport
  miniaudio            Audio
  Opus                 Voice chat codec
  Dear ImGui           Editor and in-game debug interface
  cimgui               C interface to Dear ImGui
  ImGuizmo             Editor gizmos
  ImGuiColorTextEdit   Editor code view
  cgltf                glTF model loading
  Assimp               Editor model converter (FBX, OBJ, DAE, STL, PLY, 3DS)
  stb                  Image and font loading
  Roboto               Interface and default World Text font
  Font Awesome         Interface icons
  SMAA                 Antialiasing (SMAA 1x shaders and lookup textures, iryoku/smaa)
  Bevy                 Sky and atmosphere shaders (bevy_pbr atmosphere, MIT)
  NVIDIA DLSS          Upscaling (DLSS SDK and runtime; NVIDIA GeForce RTX only)
  FidelityFX FSR 2     Upscaling (FSR temporal upscaler and Vulkan backend, AMD)
  FidelityFX FSR 1     Upscaling (FSR 1 EASU and RCAS shaders, AMD)
  KEMAR HRTF data      Headphone 3D audio
