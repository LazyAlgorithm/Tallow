# Engine trim/AOT warnings a NativeAOT export accepts (tools/csharp_native.py), each reviewed.
#
# A line: <codes> <origin> <reason>. Codes are IL numbers separated by commas, or * for any. The origin is the
# method (or type, for all its methods) the warning comes from, as the ILCompiler names it, without parameters;
# a compiler-made name such as `<CallbackMask>g__Check|91_0` is matched by its start (`...<CallbackMask>`).
#
# An engine warning that is not here fails the export: review it, then add it with its reason or change the code.
# Warnings in the game's own code always fail (the author fixes them, or keeps them with
# [UnconditionalSuppressMessage] and a justification); warnings in packages and .NET itself are reported only.
#
# Why most reflection here is safe: the export keeps every game assembly whole (TrimmerRootAssembly), so fields,
# constructors and methods of game types are never trimmed; and Tallow.Build generates the generic code that
# reflection asks for at run time (Tallow.AotRoots.g.cs: List<T>, T[], TryGetComponent<T> of every Inspector field
# type). Nothing the game runs every frame appears here: Tallow.Build writes one table per assembly
# (Tallow.FieldTables.g.cs) for fields (Inspector, saves, [Sync]), lifecycle callback masks, .tui handlers, [Rpc]
# methods and behaviour-node settings, and the runtime's only remaining reflection over game types is the fallback
# for a type from a package, suppressed in the source with its reason.

# Hot reload and the collectible load context: JIT only. NativeAOT's LoadGame takes the compiled-in registry and
# ReloadGame refuses, so none of this runs in a NativeAOT game.
*                  Tallow.ManagedRuntime.ReloadMigrator                                  hot reload (JIT only)
IL2026             Tallow.ManagedRuntime.NativeEntrypoints.GameAssemblyContext            collectible load context (JIT only)
IL2026             Tallow.ManagedRuntime.NativeEntrypoints.OpenGame                       loads assemblies by path (JIT only; NativeAOT uses NativeHost.Registry)
IL2026,IL2072      Tallow.ManagedRuntime.NativeEntrypoints.CreateRegistry                 finds the generated registry by name in a loaded assembly (JIT only)
IL2026,IL2075      Tallow.ManagedRuntime.NativeEntrypoints.EditorConfigure                editor scripts (the editor runs JIT; games never call it)

# Inspector fields, saves and [Sync] text: no reflection over game types. Tallow.Build generates a field table for
# every class and struct the game declares (Tallow.FieldTables.g.cs: UnsafeAccessor members for private fields,
# default-value constructors, List<T> factories and TryGetComponent lookups). The runtime's remaining reflection is
# the fallback for a type from a package, marked [UnconditionalSuppressMessage] with its reason in the source.

# Calls by name on game types: none left. Callbacks, [Rpc] methods, .tui handlers and behaviour-node settings come
# from Tallow.Build's generated tables; a type from a package falls back to reflection, suppressed in the source.
